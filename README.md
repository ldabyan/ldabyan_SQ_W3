# Dixit Duel

## Setup and Interaction Instructions

Open `index.html` in Google Chrome using Live Server.

To play via GitHub Pages, visit the link provided on the submission page.

**Controls:**
- P1: A/D to move, F to attack, G to block
- P2: Arrow keys to move, K to attack, L to block

Press ENTER to start. First to land 3 hits wins. Press ENTER again to rematch.
