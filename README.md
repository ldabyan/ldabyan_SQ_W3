# Dixit Duel
## Setup and Interaction Instructions
Open index.html with Live Server or visit the GitHub Pages link to play in Chrome.
**Controls:**
- P1: A/D to move, F to attack, G to block
- P2: Arrow keys to move, K to attack, L to block
Press ENTER to start. First to land 3 hits wins. Press ENTER again to rematch.
## Assets
All sounds (punch_1.wav through punch_9.wav, win.wav, background.mp3) were provided by the course instructor as part of the Week 3 starter files.
